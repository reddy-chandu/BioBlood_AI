How It Works

Step 1

The user selects and uploads a fingerprint image, which is securely transmitted to the server for further processing.

Step 2

The image received on the server is preprocessed to ensure it meets the input requirements of our AI model.

Step 3

The preprocessed image is then passed as input into our AI model, which analyzes the fingerprint patterns to predict the blood group.

Step 4

The predicted blood group along with the confidence level is then displayed to the user in the frontend.
